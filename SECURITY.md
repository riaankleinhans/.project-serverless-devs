# Security Policy

## Reporting Security Issues

The Serverless Devs maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/Serverless-Devs/Serverless-Devs/security/advisories/new) form.

For more details, see the [Serverless Devs security policy](https://github.com/Serverless-Devs/Serverless-Devs/blob/master/SECURITY.md).
